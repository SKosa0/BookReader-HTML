## 概要

BookReader は、EPUBの小説や画像コミック書庫を、ブラウザ上で読むための単体HTML形式のリーダーです。HTMLファイルを開いて使用でき、通常の読書データや取り込んだ書籍ファイルは利用中の端末・ブラウザ内に保存されます。

## ダウンロード・起動

1. Releases から `BookReaderV4.5.0RC1.html` をダウンロードします。
2. ダウンロードしたHTMLファイルを、対応するブラウザで開きます。
3. 「本を追加」からEPUBまたは対応する書庫ファイルを選択します。

本ソフトウェアは単体HTMLとして配布しています。通常利用のために別途ライブラリをダウンロードする必要はありません。

## 主な機能

### 書籍・コミックの読み込み

- EPUBの読み込み
- ZIP・CBZ内の画像コミックの読み込み
- RAR・CBR内の画像コミックの読み込み
- ZIP内に含まれる複数EPUBの展開・追加
- フォルダ単位での書籍追加

**RARの対応範囲**

- RAR4：Store形式に対応
- RAR5：非ソリッド形式に対応（フィルター処理を含む）
- RAR4の圧縮形式、ソリッド圧縮、分割RAR、暗号化RARは非対応です。
- RAR5は書庫全体を一括でメモリに展開せず、ヘッダーを読み取り、必要なデータを取得する方式です。

### 小説の読書

- 縦書き・横書き
- EPUB内のルビ・書式の表示
- 文字サイズ、行間、余白、文字の太さなどの調整
- TTF・OTF・WOFF・WOFF2形式のカスタムフォント
- 読み方や表示設定の保存

### コミックの読書

- ページ表示
- 見開き表示
- 表紙の単独表示
- 見開き位置の補正
- ページ一覧（スライド表示）
- ページ送り・戻しの操作設定とアニメーション
- 表示倍率・背景などの調整

### 本棚・読書管理

- 本棚・フォルダによる整理
- シリーズの自動整理
- タイトル・著者名による検索
- 読書位置・進捗の保存
- しおり、メモ、ハイライト
- 本文検索
- 読書統計

### 表示・操作

- 日本語・英語のUI切り替え
- 複数の表示テーマ・アクセントカラー
- モバイル・タブレット・PC向けのレイアウト調整
- ホーム／ライブラリなどのナビゲーション配置設定

### バックアップ・データ管理

- 手動バックアップ・復元
- 手動バックアップでは、設定・読書情報に加えて、選択により書籍ファイルを含められます。
- 自動バックアップは7日ごとに作成され、端末内に最新1世代を保持します。
- 自動バックアップに含まれるのは設定・本棚情報・読書位置などの管理データです。書籍本体、カスタムフォント、表紙キャッシュは含まれません。
- 保存容量の確認と、IndexedDB内のデータに対する読み取り専用診断

## データ保存とプライバシー

- 取り込んだ書籍ファイルはIndexedDBに保存されます。
- 設定や読書情報などはブラウザのlocalStorage等に保存されます。
- 通常の読み込み・読書のために、書籍ファイルをBookReaderのサーバーへアップロードする仕組みはありません。
- 辞書機能を使用すると、選択した文章の先頭最大30文字がWeblioのURLに含まれ、Weblioへアクセスします。辞書機能を使用しない場合、この機能による文章の送信は行われません。
- ブラウザのサイトデータ削除、閲覧データ削除、プライベートブラウズの利用環境などによって、保存データが消失または保持されない場合があります。定期的に手動バックアップを作成してください。

## 動作環境について

BookReaderはブラウザのHTML、JavaScript、IndexedDB、File APIなどを使用します。利用するブラウザやOSによって、ファイルの選択方法、保存容量、バックグラウンド動作などに違いがあります。

すべてのブラウザ・端末での動作を保証するものではありません。RC1時点で確認できていない環境については、動作確認済みとして扱わないでください。

## 既知の制限

- RAR4はStore形式のみ対応です。
- RAR5は非ソリッド形式が対象です。
- 分割RARおよび暗号化RARには対応していません。
- 自動バックアップには書籍ファイル・カスタムフォント・表紙キャッシュは含まれません。
- 辞書機能の利用時は、選択した文章の先頭最大30文字がWeblioへのアクセスURLに含まれます。
- ブラウザの保存領域が不足している場合、書籍や設定を保存できないことがあります。
