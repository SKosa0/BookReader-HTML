# BookReader

単一のHTMLファイルだけで動作する、ローカル完結型の電子書籍・コミックリーダーです。  
サーバーへの書籍アップロードは一切行わず、すべての書籍データ・しおり・メモ・設定をお使いの端末内（IndexedDB / localStorage）に保存します。

- **Current Version**: `V4.5.0RC1`
- **Creator**: Kosa ([X: @SKosa_0](https://x.com/SKosa_0))

---

## 主な特徴

- **単一HTML・オフライン動作**
  - 外部CDNからスクリプトやフォントを読み込まず、HTMLファイルを開くだけで動作します（辞書検索機能を使用した場合のみ Weblio へ遷移します）。
- **対応フォーマット**
  - **EPUB**（小説・縦書き／横書き切替、ルビ、カスタムフォント TTF/OTF/WOFF/WOFF2 対応）
  - **ZIP / CBZ / RAR / CBR**（画像アーカイブをコミック用EPUBとして読み込み・閲覧。RAR4 Store / RAR5 非ソリッド対応）
- **読書体験**
  - ページ式／スクロール式、見開き表示・見開き1ページズレ補正、ページスライドビュー
  - ハイライト・メモ・しおり・本文検索・辞書検索
  - テーマ（自動 / ライト / セピア / ダーク / OLED黒）、アクセントカラー変更、日本語／英語 UI
- **ライブラリ・ストレージ管理**
  - シリーズ自動整理・タイトルによる自動仕分け・コレクション管理
  - 保存容量の確認・IndexedDB 孤立データ診断（読み取り専用）
  - 軽量自動バックアップ（設定・読書進捗のみ）／手動バックアップ（書籍本体含む）

---

## 使い方

1. リリースまたはリポジトリから `BookReaderV4.5.0Beta.html` をダウンロードします。
2. お使いのブラウザ（Chrome / Safari / Edge / Firefox など）で開きます。
3. 「本を追加」から EPUB / ZIP / CBZ / RAR ファイルを選択して読み込みます。

> **注意**: ブラウザの「サイトデータの削除」やプライベートブラウズ終了時に、IndexedDB に保存された書籍データも消去される場合があります。大切なデータは「設定 → データ → バックアップ」から定期的な書き出しをおすすめします。
